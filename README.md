# SAF Mapping Unit 51st Anniversary

A static microsite built in 2021 for the 51st anniversary of the SAF Mapping Unit. It has a home
page with an image slideshow and pages on the unit's history, its humanitarian assistance and
disaster relief (HADR) work, personal reflections, and an anniversary video.

## View it

No build step: open `index.html` in a browser. The pages are plain HTML and CSS with a slide-out
side navigation.

| Page | File |
| --- | --- |
| Home and slideshow | `index.html` |
| History | `history.html` |
| HADR | `hadr.html` |
| Reflections | `reflections.html` |
| Anniversary video | `safmuvideo.html` |
| More | `more.html` |
